# Участие в разработке

Спасибо за интерес к GeraK TV Launcher.

## Перед изменениями

1. Проверьте, что изменение относится к назначению Android TV-лаунчера.
2. Сохраните поддержку управления с пульта и D-pad.
3. Не меняйте `applicationId`, `minSdk` и поведение выбора HOME без необходимости.
4. Не добавляйте сбор персональных данных или сетевые зависимости без явного обоснования.

## Проверка

Перед отправкой изменений выполните:

```bash
./gradlew --no-daemon assembleDebug
```

Для Windows:

```powershell
.\gradlew.bat --no-daemon assembleDebug
```

## Pull Request

В описании укажите:

- что изменено и зачем;
- затронутые устройства / версии Android;
- результат сборки;
- результат проверки на Android TV или эмуляторе, если она проводилась.

Не указывайте проверку на устройстве, если выполнялась только компиляция.
